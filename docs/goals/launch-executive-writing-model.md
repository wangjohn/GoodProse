# Launch the GoodProse research goal

Paste this single command into Codex from the GoodProse repository:

```text
/goal Execute the GoodProse executive-writing research contract in docs/goals/executive-writing-model.md. First read AGENTS.md, programs/executive-writing/AGENTS.md, programs/executive-writing/configs/HARNESS_PREFLIGHT.md, and the existing program reports. Work autonomously on codex/executive-model-program, maintain the progress and cost ledgers after every checkpoint, and continue until every contract stopping condition is met. Continue all safe, useful work while rights, budget, provider, or human decisions are pending; pause only when one becomes the sole blocker and no evidence-bearing work remains.
```

The launcher intentionally states one durable objective and points to the
versioned contract for validation, checkpoints, constraints, and the stopping
condition. Update and commit the contract instead of growing this command into
an unreviewable prompt.
