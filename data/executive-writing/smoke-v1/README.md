# Project-authored smoke corpus v1

This directory stores only the compact provenance manifest for the first real
MLX fine-tuning smoke run. The 48 chat records are rebuilt deterministically
under ignored `data/derived/`; they contain fictional project-authored facts and
no named-source, imported, private, B2, or Tier C material.

The corpus is authorized only to validate this project's training, inference,
evaluation, and run-manifest path. It is deliberately small and templated, so
its results cannot support a model-quality or production claim.

Rebuild it with the command recorded in `manifest.json`.
