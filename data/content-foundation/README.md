# Content-foundation exemplars

This collection identifies source documents with strong technical reasoning and decision content. It does not endorse their prose style or treat an upstream document as a supervised example.

Content-foundation exemplars help GoodProse authors and evaluators identify facts worth preserving when technical material is adapted for executives:

- the decision, problem, scope, and intended outcome;
- assumptions, constraints, evidence, and uncertainty;
- material customer, technical, financial, security, and operational consequences;
- alternatives, rationale, commitments, and open questions.

[`index.json`](index.json) references immutable documents in [`../raw/`](../raw/) by document ID. It does not copy upstream files. The train, development, and test roles remain defined by [`../sources.json`](../sources.json); membership in this collection never overrides those boundaries.

Use these documents to design fact inventories and create grounded transformation pairs. Do not ask a model to imitate their sentences unless the same material also appears as an approved style reference.
